# TaxMTD Releases

Signed desktop binaries for [TaxMTD](https://taxmtd.uk).

- Latest: [releases page](https://github.com/TaxMTD/TaxMTD-releases/releases/latest)
- Source code lives in the private `TaxMTD/UC-tauri` repo.
- Auto-update manifest: `latest.json` attached to each release.

Built and signed via GitHub Actions on every `v*` tag push to UC-tauri.
